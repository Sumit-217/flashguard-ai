# Backend Service

This directory will contain the **FastAPI** backend service for FlashGuard AI.

## Overview
- **Language**: Python 3.11+
- **Framework**: FastAPI + Uvicorn
- **Data Validation**: Pydantic
- **Database**: PostgreSQL with PostGIS extension
- **Role**: Central integration layer between mobile clients, AI/risk engine, admin dashboard, IoT broker, and alert delivery mechanisms.

> **Note**: The FastAPI backend application and dependencies will be initialized here during the implementation stage (Stage 2).
