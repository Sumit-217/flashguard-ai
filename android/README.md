# Android / Mobile Application

This directory will contain the **Flutter** mobile application for FlashGuard AI.

## Overview
- **Framework**: Flutter (Dart)
- **State Management**: Riverpod
- **Local Storage / Caching**: Drift + SQLite
- **Networking**: Dio
- **Location & Notifications**: Geolocator, Firebase Cloud Messaging (FCM), Flutter Local Notifications

> **Note**: The Flutter application will be initialized and created here during the implementation stage (Stage 3).
