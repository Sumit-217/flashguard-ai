# AI & Risk Assessment Engine

This directory will contain the AI models, datasets, notebooks, and risk calculation pipeline for FlashGuard AI.

## Structure
- `models/` - Serialized model weights and configurations.
- `datasets/` - Training data, historical disaster records, and sample feeds.
- `notebooks/` - Jupyter notebooks for exploratory data analysis (EDA) and experimental models.
- `src/` - Production risk engine source code (rules, geospatial calculations, ML inference).
- `tests/` - Unit and integration tests for AI/risk modules.

## Technology
- Python, NumPy, Pandas, scikit-learn, GeoPandas, Shapely.

> **Note**: Datasets, notebooks, and models will be added during the AI/Risk Engine stage (Stage 4).
