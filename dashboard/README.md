# Admin Dashboard

This directory will contain the administrator monitoring dashboard for FlashGuard AI.

## Overview
- **Framework**: React + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Mapping**: Leaflet / React-Leaflet
- **Capabilities**: Centralized incident monitoring, risk-zone visualization, live IoT sensor metrics, alert broadcasts, and emergency message coordination.

> **Note**: The React/Vite application will be initialized here during Stage 6.
